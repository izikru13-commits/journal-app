# journal-app

שתי אפליקציות עצמאיות שרצות בדפדפן, ללא שרת וללא התקנה. כל המידע נשמר מקומית בדפדפן (localStorage), ובאירוח שמציע מאגר מסמכים משותף גם מסתנכרן בין המכשירים.

## `index.html` — מערכת ניהול יומנים
ניהול יומני למידה: יצירת יומנים, משימות שבועיות, קישורים ורפלקציה יומית.

## `hours.html` — ניהול שעות עבודה
מעקב אחרי שעות עבודה וחישוב השכר:

- **כמה משמרות ביום אחד** — כל יום יכול להכיל כמה טווחי שעות (בוקר וערב), והשעות מסתכמות יחד
- רישום לפי שעת התחלה וסיום (כולל משמרות שחוצות חצות), או לפי מספר שעות ידני עם כפתורי ±חצי שעה
- **יום טיול** ו**שבת** — תוספות נפרדות, לכל אחת אפשר לקבוע אם היא מחליפה את התשלום השעתי או מתווספת אליו
- **נסיעות** — סכום לכל יום, עם ברירת מחדל שנקבעת בהגדרות
- סיכום חודשי: שעות, סה״כ ברוטו, ימי טיול ושבתות, וסכום שטרם שולם
- סימון תשלום לרישום בודד או לחודש שלם
- **דוח חודשי** — טבלה של כל יום בחודש (תאריך, משמרות, שעות, תוספות, לתשלום) שניתן להוריד כמסמך להדפסה או כ‑CSV לאקסל
- סיכום מצטבר לכל התקופה

### תעריפים (ניתנים לשינוי במסך ההגדרות)

| הגדרה | ברירת מחדל | מקור |
| --- | --- | --- |
| תעריף לשעה | 50 ₪ | סעיף 15 בהסכם |
| יום טיול | 300 ₪ (בנוסף לשעות) | סעיף 17 |
| שבת | 550 ₪ (במקום השעות) | סעיף 18 |
| נסיעות | לפי יום | סעיף 15 |
| שעות ביום טיול | 8 | ברירת מחדל לנוחות |

הסכומים המוצגים הם ברוטו, לפני ניכויי החובה שמנוכים מהשכר (סעיף 19). הדוח החודשי מציין שהשכר עבור החודש משולם עד ה‑9 לחודש שאחריו (סעיף 20).
