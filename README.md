# journal-app

שתי אפליקציות עצמאיות שרצות בדפדפן, ללא שרת וללא התקנה. כל המידע נשמר מקומית בדפדפן (localStorage).

## `index.html` — מערכת ניהול יומנים
ניהול יומני למידה: יצירת יומנים, משימות שבועיות, קישורים ורפלקציה יומית.

## `hours.html` — ניהול שעות עבודה
מעקב אחרי שעות עבודה וחישוב השכר:

- רישום יום עבודה לפי שעת התחלה וסיום (כולל משמרות שחוצות חצות) או לפי מספר שעות ידני
- סימון **יום טיול** שמזכה בבונוס בנוסף לתשלום לפי שעות
- סיכום חודשי: שעות, סה״כ לתשלום, ימי טיול וסכום שטרם שולם
- סימון רישומים בודדים או חודש שלם כ"שולם"
- ייצוא החודש לקובץ CSV
- סיכום מצטבר לכל התקופה

### תעריפים (ניתנים לשינוי במסך ההגדרות)

| הגדרה | ברירת מחדל |
| --- | --- |
| תעריף לשעה | 50 ₪ |
| בונוס יום טיול | 300 ₪ |
| שעות ביום טיול | 8 |

כך יום עבודה רגיל של 8 שעות שווה 400 ₪, ויום טיול של 8 שעות שווה 700 ₪ (400 ₪ + 300 ₪ בונוס).
שינוי התעריפים משפיע גם על רישומים קיימים, כך שכל החישובים תמיד לפי התעריף העדכני.
