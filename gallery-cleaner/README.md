# ניקוי בהחלקה (SwipeClean) – אפליקציית אייפון

מנקים את הגלריה כמה דקות ביום, תמונה אחרי תמונה:

| תנועה | פעולה |
|---|---|
| ימינה | לשמור |
| שמאלה | למחיקה |
| למעלה | למועדפים (המועדפים של אפליקציית תמונות) |
| ↶ | ביטול הפעולה האחרונה |

- **גישה לכל הגלריה**: כל התמונות והסרטונים, כולל אלבום וואטסאפ וצילומי מסך (יש סינון לפי קטגוריה).
- **המשך מאותו מקום**: כל פריט שכבר עברת עליו נשמר, כך שכל יום ממשיך מהמקום שבו עצרת.
- **שום דבר לא נמחק בלי אישור**: בסוף כל סבב יש מסך סיכום (אפשר להציל תמונות בהקשה), ורק אחרי אישור – וגם iOS מבקש אישור. הפריטים נשארים 30 יום ב״נמחקו לאחרונה״.
- **תוכנית יומית**: יעד יומי, רצף ימים 🔥, ותזכורת בשעה שנוחה לך.
- **פרטיות**: הכל קורה בטלפון. בלי חשבון, בלי שרת, בלי העלאה לענן.

## בנייה

GitHub Actions (`.github/workflows/ios-build.yml`) בונה קובץ `SwipeClean.ipa` לא חתום בכל push.
הורדה: לשונית **Actions** ← ההרצה האחרונה ← **Artifacts** ← `SwipeClean-ipa`.

## התקנה על אייפון

**בלי מק (Windows או Mac):**
1. מתקינים את [Sideloadly](https://sideloadly.io) במחשב.
2. מחברים את האייפון בכבל, גוררים את `SwipeClean.ipa` ל-Sideloadly ומתחברים עם ה-Apple ID.
3. באייפון: הגדרות ← כללי ← VPN וניהול התקנים ← לאשר את המפתח.
4. באייפון עם iOS 16 ומעלה: הגדרות ← פרטיות ואבטחה ← מצב מפתח ← להפעיל.

עם Apple ID חינמי צריך לחתום מחדש כל 7 ימים (ב-Sideloadly אפשר להפעיל רענון אוטומטי).
עם חשבון מפתח בתשלום ($99 לשנה) החתימה מחזיקה שנה ואפשר גם TestFlight.

**עם מק:**
```bash
brew install xcodegen
cd gallery-cleaner && xcodegen generate
open SwipeClean.xcodeproj   # בוחרים Team ב-Signing ומריצים על האייפון
```
