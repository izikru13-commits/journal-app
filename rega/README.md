# רגע (Rega)

אפליקציית אייפון אישית להפחתת זמן מסך: שער עם השהיה לפני אפליקציות מסיחות, נעילות קבועות שרק מפתח פיזי מסיים מוקדם, נתונים כנים ופעילויות חלופיות. בלי שרת, בלי חשבון, הכל נשאר בטלפון.

## התקנה ראשונה (על המק)

1. מתקינים Xcode מה-App Store, פותחים אותו פעם אחת ומאשרים את ההתקנות.
2. Xcode ← Settings ← Accounts ← ‏+ ← מתחברים עם ה-Apple ID של חשבון המפתחים.
3. מורידים את הקוד:
   ```bash
   git clone https://github.com/izikru13-commits/journal-app.git
   cd journal-app/rega
   ```
4. מריצים: `scripts/setup.sh` (הסקריפט בודק את Xcode, מתקין XcodeGen ומחפש את ה-Team ID).
   אם הוא לא מוצא את ה-Team ID: נכנסים ל-developer.apple.com/account ← Membership details ← Team ID (10 תווים), ומריצים `scripts/setup.sh ABCDE12345`.
5. באייפון: מחברים בכבל ← ״לסמוך על המחשב הזה?״ ← לסמוך.
6. באייפון: הגדרות ← פרטיות ואבטחה ← מצב מפתח ← להפעיל (הטלפון יופעל מחדש).
7. באייפון: הגדרות ← זמן מסך ← להפעיל את זמן מסך.
8. מריצים: `scripts/install-device.sh`. האפליקציה נבנית, נחתמת ומותקנת.

## התקנת עדכונים

```bash
cd journal-app && git pull
cd rega && scripts/install-device.sh
```
הנתונים נשמרים בין עדכונים (הם ב-App Group, לא בתוך האפליקציה).

## אם המגנים הפסיקו לעבוד

1. פותחים את רגע: כל פתיחה מחילה מחדש את כל המגנים.
2. הגדרות ← מערכת ← ״לתזמן מחדש את כל הנעילות״.
3. הגדרות ← מערכת ← ״אישור Screen Time מחדש״.
4. באייפון: הגדרות ← זמן מסך ← לוודא שזה דלוק, ובתחתית ״אפליקציות עם גישה לזמן מסך״ לוודא שרגע מופיע ודלוק.
5. אם עדיין לא: מוחקים את רגע (רק כשאין נעילה קשיחה), מפעילים מחדש את האייפון ומריצים שוב `scripts/install-device.sh`. אחרי מחיקה האפליקציות המסיחות צריך לבחור מחדש (Apple לא שומרת אותן).

## כשהחתימה פגה

עם חשבון מפתחים בתשלום, פרופיל הפיתוח תקף בערך שנה. כשהוא פג, רגע לא ייפתח (ההרחבות מפסיקות לרוץ):
1. מחברים את האייפון למק.
2. מריצים `scripts/install-device.sh`. הדגל ‎`-allowProvisioningUpdates` יוצר פרופיל חדש.
3. אם יש שגיאת חתימה: פותחים את `Rega.xcodeproj` ← לוחצים על הפרויקט ← Signing & Capabilities ← לוודא שה-Team נבחר בכל שש המטרות ← מריצים שוב.

ההתקנה מעל הגרסה הקיימת שומרת את כל הנתונים.

## רשימת בדיקות במכשיר

1. אונבורדינג: אישור Screen Time, התראות, בחירת 2–3 אפליקציות, יצירת מפתח והדפסה/שמירה.
2. פותחים אפליקציה מסיחה ← מסך ״רגע.״ כהה עם מספר הניסיונות היום.
3. ״ויתרתי״ ← האפליקציה נסגרת, ובמסך הבית של רגע ״ויתרתי״ עולה ב-1.
4. ״בכל זאת לפתוח״ ← מגיעה התראה ← הקשה ← נשימה של 8 שניות ← סיבה ← דקה אחת ← ״לפתוח עכשיו״ (באינסטגרם/יוטיוב וכו׳) ← האפליקציה נפתחת.
5. אחרי דקה בערך המגן חוזר לבד, גם בלי לפתוח את רגע.
6. בפתיחה מאושרת שנייה באותו יום, הנשימה היא 12 שניות.
7. ״שעמום״ ← מוצעת פעילות חלופית ← ״אעשה את זה במקום״ נספר כוויתור.
8. נעילה עכשיו 15 דקות, קשיחה: המגן מציג רק ״סגירה״; סריקת ה-QR המודפס מסיימת אותה.
9. בזמן נעילה קשיחה: לנסות למחוק את רגע (לחיצה ארוכה). **חשוב לדווח אם אפשר או אי אפשר**: זו הבדיקה של denyAppRemoval.
10. יציאת חירום: להקליד את המשפט בדיוק; המונה יורד ל-2.
11. נעילת שינה: בלילה הראשון לבדוק שהיא מתחילה ב-23:00 ונגמרת ב-07:00.
12. ווידג'ט במסך הבית ובמסך הנעילה מציג את המספרים של היום.
13. מסך הנתונים: דוח זמן המסך מ-iOS נטען (לפעמים לוקח כמה שניות).
14. (אם הופעל) תקציב יומי: התראה ב-80%, נעילה ב-100%.
